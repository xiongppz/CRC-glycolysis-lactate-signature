# CRC Glycolysis/Lactate Metabolism Multi-omics Analysis

## Overview

This repository contains the R code used for the bioinformatics and multi-omics analyses in our colorectal cancer (CRC) study investigating a glycolysis/lactate metabolism-related six-gene prognostic signature, tumor microenvironment features, and single-cell transcriptional heterogeneity.

The main analysis script integrates bulk transcriptomic analysis, WGCNA, prognostic modeling, immune microenvironment analyses, single-cell RNA-seq analysis, pseudotime analysis, and cell-cell communication analysis.

## Main script

- `CRC_analysis.R` — complete analysis script used in this study.

## Main analyses included

The script contains the following analysis modules:

- TCGA-COAD expression preprocessing and differential expression analysis
- Weighted gene co-expression network analysis (WGCNA)
- Candidate gene intersection and functional enrichment analysis
- Univariate Cox regression and LASSO-Cox prognostic model construction
- Internal validation and external validation using GSE161158
- Clinical Cox regression, model comparison, C-index, time-dependent AUC, Brier score, bootstrap correction, and nomogram analysis
- ESTIMATE, CIBERSORT, ssGSEA, and related immune microenvironment analyses
- TCIA IPS analysis
- Exploratory IMvigor210 immunotherapy analysis
- Single-cell RNA-seq analysis of GSE221575 using Seurat
- Harmony batch correction and kBET assessment
- Cell-type annotation and epithelial-cell subclustering
- Lactate-related transcriptional scoring using `AddModuleScore`
- Monocle 2 pseudotime analysis
- CellChat analysis, including GALECTIN, MK, and LAMININ signaling

│   └── [10x Genomics sample folders]

Several analysis sections generate intermediate `.RData`, `.RDS`, `.txt`, `.csv`, and figure files that are subsequently used by later sections.

Some analysis sections additionally require external input files such as DAVID enrichment outputs, TCIA data, IMvigor210 data, or immune-cell gene-set files. These files should be obtained from their original sources and placed in the locations expected by `CRC_analysis.R`.

## Running the analysis

1. Download or clone this repository.
2. Obtain the required public datasets and external resource files.
3. Place the files in the project structure expected by `CRC_analysis.R`.
4. Start R/RStudio with the repository root as the working directory.
5. Install the required R/Bioconductor packages if necessary.
6. Run the analysis sections in `CRC_analysis.R` sequentially.

Because several downstream sections use files generated by earlier sections, running isolated sections may require the corresponding intermediate files.

## Reproducibility

The repository uses relative file paths and does not contain author-specific local absolute paths.

To record the final software environment, run:

```r
capture.output(sessionInfo(), file = "sessionInfo.txt")
```

A helper script, `generate_sessionInfo.R`, is provided for convenience.

The generated `sessionInfo.txt` should be created in the same R environment used to generate the final manuscript results and should replace the supplied template before public release.
